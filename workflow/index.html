工作流教程

四步法:定方向 → 立契约 → 生成 → 终检

  1. 01

    定方向

    ui-ux-pro-max 按行业推理生成设计系统骨架;项目已有品牌规范的,跳过此步。

    uipro init --ai claude --global
    跳到速查手册:装机 →
  2. 02

    立契约

    在项目根写 DESIGN.md。新项目手写 tokens + 理念;老项目用/impeccable document 从现有代码反向生成。写完先校验一遍,对比度不达 WCAG AA 会被直接报出。

    npx @google/design.md lint DESIGN.md
    跳到速查手册:校验 →
  3. 03

    生成

    frontend-design 按 DESIGN.md 契约生成;电影质感项目显式点名 high-end-visual-design(与 frontend-design 职责重叠,二选一主用,特殊风格项目时才点名 taste)。 动效细节交给 emil 的 animate 与 review-animations。

    跳到速查手册:装机 →
  4. 04

    终检

    /impeccable audit(a11y / 性能 / 响应式)加 /impeccable polish 收尾; 成品页——包括外部工具生成的——用 npx impeccable detect <URL> 扫一遍。

    npx impeccable detect <URL>

    全局 hook 已生效:每次 Edit/Write UI 文件自动即时扫,Stop 时全规则深扫,不用手动跑。

    跳到速查手册:扫描 →

两个装机坑

impeccable 安装器不走系统代理

GitHub releases 直连超时 → 用 https://gh-proxy.com/ 前缀手动下载 bundle,务必核对 sha256(.sig.json 清单里有官方哈希)。

同名 skill 双源抢激活

skills add 装完同名 skill 后,旧 plugin 要停用 (claude plugin disable):同一会话里两个同名 skill 会抢 description 匹配。
