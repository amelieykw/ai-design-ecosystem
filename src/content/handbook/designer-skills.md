## designer-skills · 详细教程

## 是什么

Owl-Listener 维护的专业设计师向完整工作流仓库。README 口径:273 skills + 76 commands 跨 33 个插件,组织为 5 大集合(Design practice / AI product design / UX program management / Design leadership / Inclusive design)——"9 插件"只是 Design practice 单集合的口径,其余四集合各居独立仓库、由本 marketplace 汇聚;仓库数字持续增长,以 README 实时值为准。
全景图明确本机"故意不装"——273 skills 对个人工作流过重;本机同类的流程闭环已由 impeccable(init→craft→critique→polish)承担,知识层由 ui-ux-pro-max + ui-design-brain 承担。

## 安装

暂不安装(刻意保留的空白区)。若未来确需整装:

```bash
claude plugin marketplace add Owl-Listener/designer-skills
```

再在 `/plugin` 面板按集合挑装,不建议 273 个全量启用。

## 什么时候用

什么时候值得装:接手完整设计咨询项目、需要正式的用户研究/策略文档/交付物链路(而非快速出页面)时;
需要其中某一环(如研究方法)时按集合挑装,不要全量;
什么时候不用:个人开发者的"出页面"工作流,impeccable + ui-ux-pro-max 已覆盖,再叠 273 skills 只会让 skill 匹配变慢、互相抢激活。
