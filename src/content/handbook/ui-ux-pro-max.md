## ui-ux-pro-max · 详细教程

## 是什么

设计智能数据库 + Python BM25 搜索:输入产品类型,输出完整设计系统。
内含 192 行业规则 / 79 UI 风格 / 192 色板 / 74 字体搭配 / 119 UX 指南。
本机已从 v2.0.1 升级到 v2.15.0,旧 plugin 版已 disable 避免同名双源抢激活。

见 frontmatter `install` 字段的命令,落盘 `~/.claude/skills/ui-ux-pro-max/`。

做 UI 评审时对照 119 条 UX 指南逐条核对。
