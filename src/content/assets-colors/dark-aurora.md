# 极光深

## 使用建议

服务器监控、代码编辑器、IoT 仪表盘的极客暗色。极光绿代表"运行/正常",警橙代表"警告",危险红代表"宕机"。和 JetBrains Mono、Fira Code 搭配出"运维台"质感。

## 对比度提示

雪白字 `#F8FAFC` 在极地深 `#0F172A` 上达 18:1。极光绿 `#22C55E` 在极地深上达 8:1,做"在线"状态指示色非常醒目。
