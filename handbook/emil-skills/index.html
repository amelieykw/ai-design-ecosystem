emil-skills · 详细教程

是什么

Vercel/Linear 出身的设计工程师 Emil Kowalski(Sonner 13M 周下载、Vaul 作者)的动效品味 skill 集。 核心成员:animate(正确的曲线/时长)、review-animations(严格审查)、apple-design(WWDC 设计原则转译到 web)、animation-vocabulary(把“那个弹一下的东西”变成精确术语)、prototype(多版本切换对比)。 本机已装 11 个 skills,作为所有项目的动效品味基线。

安装

见 frontmatter install 字段的命令,提示时选全局,落盘 ~/.claude/skills/。

什么时候用

写任何带过渡/弹性的交互动效前先读 animate 定曲线时长; 动效做完跑 review-animations 严格审查; 说不清“想要那种感觉”时用 animation-vocabulary 反查精确术语。
