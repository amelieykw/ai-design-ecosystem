awesome-agent-conventions

AI agent 约定文件野外指南:22 个约定跨 11 类(AGENTS.md/CLAUDE.md/SKILL.md/DESIGN.md/llms.txt/ai.txt…),每条含文件名、主要读者、spec 来源、成熟度分级与真实仓库实例(持续增长,以 README 实时值为准)

awesome-agent-conventions · 详细教程

是什么

ItamarZand88 维护的约定文件目录(脚本生成 README,内容经 CI verify):22 个约定跨 11 个类别,从 AGENTS.md/CLAUDE.md 这类项目指令到 SKILL.md、MCP 配置、llms.txt、auth.md/ai.txt 这类 agent-web 信任格式,DESIGN.md 单列于 Design 类。每条给:惯用文件名、主要读者、spec 来源、成熟度标记(🟢广泛采用/🟠早期/🔵仅提案)加脚本抓取的真实仓库实例。 与库内分工:awesome-design-md 收录 DESIGN.md 的成品实例,这里回答“所有 agent 约定文件各自是什么、谁认、成熟到什么程度”——两库正好互补。

安装

纯文本资料库,无需安装——浏览 GitHub 仓库或 git clone 到本地查阅即可。

什么时候用

拿不准某个约定文件该叫什么、给哪个工具读、是否够成熟可以押注时,查对应条目; 给团队定 AI 协作规范(哪些文件进 repo 根、哪些进 .well-known)前,先看它的采纳度分级避免自造轮子; 什么时候不用:已经确定要写 DESIGN.md 内容本身——那是 awesome-design-md 的素材活,不是查目录。
